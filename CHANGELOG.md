# Ändringslogg / Changelog

## Ej släppt / Unreleased

### Svenska
- **Originalfakturorna stannar i din egen mapp** — bevakade mappar kopierar inte längre originalen till `data/attachments/`: fakturan i registret pekar i stället på filen där den ligger i din originalmapp, och betal-PDF:en hämtar originalet via den sökvägen. Har en fil flyttats eller raderats sedan registreringen säger exporten nu ifrån (⚠ i resultatdialogen, statusraden och autoexport-loggen) i stället för att tyst hoppa över den. All fakturadata (belopp, OCR, förfallo, betald-status) ligger som förut i registret; fakturor som redan pekar på kopior i `data/attachments/` fungerar precis som tidigare.
- **Snabbvinster för kärnan** — tre förbättringar för att räkna ihop fakturor som ska betalas: **ATT BETALA står nu permanent i huvudfönstrets statusrad** (alla flikar) och i **tray-ikonens tooltip** så summan alltid är synlig utan att öppna appen; **snabbfilter-chips i Fakturor** (🔴 Förfallna · 📅 Idag & i morgon · 🗓 Inom 7 dagar) filtrerar på förfallodatum med ett klick — klicka igen för att stänga av; och **skanningen flaggar OCR med fel kontrollsiffra** (⚠ OCR-kontrollsiffra + orange text i statuskolumnen) redan i granskningslistan, innan registrering.
- **Fix: fönstret gick inte att få fram via tray-ikonen** — om en extern skärm kopplats bort (t.ex. docka/DisplayPort i vila) kunde fönstret ligga kvar på den försvunna skärmen: Qt ansåg det "synligt", så dubbelklick på tray-ikonen bara "aktiverade" ett osynligt fönster. Ny skärmvakt (`ensure_window_on_screen`) körs vid varje "Visa fönster"/tray-klick och vid start: ligger fönstret utanför alla anslutna skärmar centreras det på primärskärmen, och händelsen loggas (`WINDOW_OFFSCREEN_GUARD`).
- **Fokuspaket: bara räkna ihop fakturor som ska betalas** — åtta förbättringar som gör just det snabbare och säkrare: **OCR-kontrollsiffra (Luhn)** kontrolleras direkt i registreringsdialogen (varning medan du skriver + fråga vid spara), **dubblettvarning i realtid** så samma fakturanummer aldrig registreras två gånger för en leverantör, **beständig summarad** i Fakturor som alltid visar markeringens summa med tidigaste förfall (annars totalen att betala), **⚡ Betala idag**-knapp som markerar allt som förfaller idag/i morgon och öppnar sammanställningen, **💳 Kopiera betalinfo** i högerklicksmenyn (bankgiro + OCR + belopp färdigt för internetbanken), **Ångra med Ctrl+Z** (↩-knapp) för statusändringar som Markera betald, och **kredit-påminnelse på Dashboard** om kreditfakturor legat okvittade i över 30 dagar och riskerar att göra ATT BETALA för hög.
- **Betal-PDF:en omgjord för maximal tydlighet** — nya kolumner valda för betalning: Fakturanr, Leverantör, **OCR / referens** (det man knappar in i banken; Typ/Datum/Status borttagna), Förfallodatum och Belopp. Raderna sorteras alltid leverantör A–Ö → förfallodatum → fakturanummer, med **delsumma per leverantör** i listan. **Förfallna rader markeras röda** (fetstil + röd kantmarkering) mot betalningsdatumet. ATT BETALA står nu i 20 pt nästan-svart i en vit box med marinblå ram och guldstreck, betalningsdatumet i marinblå box med guldtext, och leverantörernas bankgiro i fetstil. Avdelarsidorna för original är vita med marinblått band och sidkontext ("2 / 5") i stället för helfärgade sidor. Hela dokumentet är dessutom **alltid ljust** — även om appen kör mörkt tema — så utskriften blir skarp och bläcksnål. Bonus: åäö skrivs nu korrekt i PDF:en (namn blev tidigare felstavade, t.ex. "Langkvist").
- **Automatisk batch-export per leverantör** (Inställningar → 🤖 Autoexport, av som standard) — när en leverantör har **10 obetalda fakturor** exporteras de automatiskt till betal-PDF med originalen bifogade och sätts som **Betald**; har leverantören färre men **närmaste förfallodatum inom 5 dagar** (eller redan förfallet) exporteras de i stället direkt och **skrivs ut ihop med originalen**, även då som Betald (annars skulle de exporteras om vid varje start). Betalningsdatum = tidigaste förfallet i batchen. Körs vid start och när fakturor ändras, tyst i bakgrunden när inget behövs, och varje körning hamnar i exporthistoriken.
- **Läsbarhets- och designpassage** — större och fetare typografi i hela appen (grund 14 px, flikar 15 px fet, tabeller 14 px, Segoe UI 11 pt som appfont) och garanterad kontrast: nära-svart fet text i ljust tema och vit fet text i mörkt (mäts med appens egen WCAG-modul, minst 7:1 för brödtext). Dashboard-korten fick temavarianter — vita kort med marinblå text och färgad överkant i ljust läge — och en gammal renderingsbug där korten ritades som tre separata ränder (väljarlös stilregel ärvdes av etiketterna) är fixad med ID-väljare + WA_StyledBackground.
- **Swish med äkta QR-kod** — donationsdialogen visar nu en QR-kod i Swishs officiella originalformat (`C<nummer>;<belopp>;<meddelande>;<mask>`, numret låst, belopp och meddelande redigerbara) till det riktiga numret **072-181 71 77**, så den kan skannas direkt i Swish-appen. Numret står som bildtext under koden och kan fortfarande kopieras. QR-biblioteket (`qrcode`) installeras automatiskt via ensure_packages; utan det visas kopieringsknappen som förr.
- **Procent i uppdateringsbalken** — nedladdningen visar nu % och MB (t.ex. "62 % · 0.9 MB / 1.5 MB") direkt i förloppsbalken, och installationsfasen visar riktig procent med filräknare ("Installerar … fil 24 av 48") i stället för en ändlös spinner som såg ut som en låsning.
- **Slå ihop markerade fakturor** — markera t.ex. 10 fakturor i Fakturor-fliken och klicka 🧮 Slå ihop markerade: du får totalsumman (krediter avdragna) och förfallodatumet från den faktura som förfaller först, med listan sorterad på förfallodatum, varning för fakturor utan datum, kopierbar sammanfattning — och export av just de markerade till betal-PDF där tidigaste förfallodatumet förifylls som betalningsdatum. Redan vid markering visar statusraden summa + tidigaste förfall.
- **Uppdateraren förbättrad** — appen kollar nu själv efter ny version i bakgrunden vid start (tyst, högst en gång per dygn, avstängbart i Inställningar-menyn) och frågar bara när det faktiskt finns en nyare build — så en gammal kopia kan inte längre vara igång ovetande. Dialogen fick återställning från senaste backupen (↩ i bak/) om en uppdatering skulle strula, och förloppsbalken visar nu även installationsfasen. Dialogen öppnas med resultatet ifyllt vid auto-kollen (ingen dubbel nätkoll).
- **Uppdatering i appen** — Hjälp → 🔄 Sök ny version … hämtar senaste releasen från GitHub, visar noteringarna och kan hämta + installera den med ett klick. Bara programfiler byts: data/, js/, ui/data/, settings.json, loggar och exporter rörs aldrig, och en backup sparas i bak/ innan något ersätts. Jämförelsen sker per commit, så även en uppdaterad v1.0.0-release hittas trots samma versionsnummer.
- **Bevakade mappar + original i betal-PDF:en** — lägg en bevakad mapp per leverantör i Import-fliken (t.ex. Pilkington, Direktglas): nya fakturafiler tolkas och registreras automatiskt, ofullständiga parkeras för granskning och samma fil importeras aldrig två gånger (innehålls-hash + dubblettkoll mot registret). Originalen kopieras till `data/attachments/<leverantör>/` och kan läggas efter betal-PDF:en (Inställningar → 📎 Inkludera originalfakturor) med avdelarsida per faktura.
- **Riktig Dashboard** — startsidan är inte längre en platshållare: fyra nyckeltalskort (ATT BETALA, FÖRFALLET, FÖRFALLER 7 DAGAR, LEVERANTÖRER) i marinblått/guld plus listan "Förfaller snart" med dubbelklick direkt till Fakturor. Samma statusregler och beloppsformat som Fakturor-fliken.

### English
- **Original invoices now stay in your own folder** — watched folders no longer copy originals to `data/attachments/`: the registered invoice instead points at the file where it lies in your original folder, and the payment PDF fetches the original via that path. If a file has been moved or deleted since registration, the export now says so (⚠ in the result dialog, the status line and the auto-export log) instead of silently skipping it. All invoice data (amounts, OCR, due dates, paid status) lives in the register as before; invoices that already point at copies in `data/attachments/` keep working exactly as before.
- **Quick wins for the core task** — three improvements for adding up invoices to be paid: **TO PAY is now permanently shown in the main window's status bar** (all tabs) and in the **tray icon tooltip**, so the total is visible without opening the app; **quick-filter chips in Invoices** (🔴 Overdue · 📅 Today & tomorrow · 🗓 Within 7 days) filter by due date in one click — click again to clear; and **scanning flags OCR numbers with a bad check digit** (⚠ OCR check digit + orange status text) right in the review list, before registration.
- **Fix: the window could not be brought up from the tray icon** — if an external monitor had been disconnected (e.g. a dock/DisplayPort display asleep), the window could remain on the vanished screen: Qt considered it "visible", so double-clicking the tray icon merely "activated" an invisible window. A new screen guard (`ensure_window_on_screen`) now runs on every "Show window"/tray click and at startup: if the window sits outside all connected screens it is centred on the primary screen, and the event is logged (`WINDOW_OFFSCREEN_GUARD`).
- **Focus pack: only add up the invoices that are to be paid** — eight improvements that make exactly that faster and safer: **OCR check digit (Luhn)** validated right in the registration dialog (warning while you type + confirm on save), **real-time duplicate warning** so the same invoice number is never registered twice for a supplier, a **persistent summary line** in Invoices always showing the selection total with earliest due date (otherwise the total to pay), a **⚡ Pay today** button that selects everything due today/tomorrow and opens the summary, **💳 Copy payment info** in the right-click menu (bankgiro + OCR + amount ready for the bank), **Undo with Ctrl+Z** (↩ button) for status changes such as Mark paid, and a **credit reminder on the Dashboard** when credit invoices have been unnetted for over 30 days and risk inflating TO PAY.
- **Payment PDF redesigned for maximum clarity** — new columns chosen for paying: Invoice no., Supplier, **OCR / reference** (what you type into the bank; Type/Date/Status removed), Due date and Amount. Rows are always sorted supplier A–Z → due date → invoice number, with a **subtotal per supplier** in the list. **Overdue rows are marked red** (bold + red edge stripe) against the payment date. TO PAY is now 20 pt near-black in a white box with a navy border and gold rule, the payment date sits in a navy box with gold text, and suppliers' bankgiro numbers are bold. Original divider pages are white with a navy band and page context ("2 / 5") instead of full-colour pages. The whole document is also **always light** — even when the app runs in dark theme — so printouts stay sharp and ink-friendly. Bonus: åäö now render correctly in the PDF (names were previously misspelled, e.g. "Langkvist").
- **Automatic batch export per supplier** (Settings → 🤖 Auto-export, off by default) — when a supplier reaches **10 unpaid invoices** they are automatically exported to a payment PDF with the originals attached and marked **Paid**; with fewer than 10 but the **nearest due date within 5 days** (or already overdue) they are exported right away and **printed together with the originals**, also marked Paid (otherwise they would re-export at every startup). Payment date = earliest due date in the batch. Runs at startup and whenever invoices change, silently in the background when nothing is due, and every run is recorded in the export history.
- **Readability & design pass** — larger, bolder typography throughout (14 px base, 15 px bold tabs, 14 px tables, Segoe UI 11 pt app font) and guaranteed contrast: near-black bold text on light themes and white bold text on dark (measured with the app's own WCAG module, at least 7:1 for body text). The Dashboard cards gained theme variants — white cards with navy text and a coloured top stripe in light mode — and an old rendering bug where cards were drawn as three separate strips (a selector-less style rule was inherited by the labels) is fixed with an ID selector + WA_StyledBackground.
- **Swish with a genuine QR code** — the donation dialog now shows a QR code in Swish's official original format (`C<number>;<amount>;<message>;<mask>`, number locked, amount and message editable) for the real number **072-181 71 77**, scannable directly in the Swish app. The number appears as a caption below the code and can still be copied. The `qrcode` library is installed automatically via ensure_packages; without it the copy button is shown as before.
- **Percentage in the update progress bar** — downloads now show % and MB (e.g. "62 % · 0.9 MB / 1.5 MB") right in the progress bar, and the install phase shows real percentage with a file counter ("Installing … file 24 of 48") instead of an endless spinner that looked like a freeze.
- **Combine selected invoices** — select e.g. 10 invoices in the Invoices tab and click 🧮 Combine selected: you get the total (credits deducted) and the due date of the earliest-due invoice, with the list sorted by due date, warnings for invoices without a date, a copyable summary — and export of exactly those invoices to a payment PDF with the earliest due date prefilled as the payment date. The status bar already shows the sum + earliest due while selecting.
- **Updater improved** — the app now checks for a new version silently in the background at startup (at most once a day, can be turned off in the Settings menu) and only asks when a newer build actually exists — an old copy can no longer keep running unnoticed. The dialog gained restore-from-latest-backup (↩ in bak/) in case an update misbehaves, and the progress bar now also shows the install phase. Auto-checks open the dialog pre-filled (no double network round-trip).
- **In-app updates** — Help → 🔄 Check for updates … fetches the latest release from GitHub, shows the notes and can download + install it in one click. Only program files are replaced: data/, js/, ui/data/, settings.json, logs and exports are never touched, and a backup is saved to bak/ before anything is replaced. Comparison is per commit, so an updated v1.0.0 release is found even with the same version number.
- **Watched folders + originals in the payment PDF** — add one watched folder per supplier in the Import tab (e.g. Pilkington, Direktglas): new invoice files are parsed and registered automatically, incomplete ones are parked for review, and the same file is never imported twice (content hash + duplicate check against the register). Originals are copied to `data/attachments/<supplier>/` and can be appended after the payment PDF (Settings → 📎 Include original invoices) with a divider page per invoice.
- **A real Dashboard** — the start page is no longer a placeholder: four stat cards (TO PAY, OVERDUE, DUE IN 7 DAYS, SUPPLIERS) in navy/gold plus a "Due soon" list with double-click straight to Invoices. Same status rules and amount format as the Invoices tab.


## v1.0.0 — 2026-10-14 (uppdaterad / updated)

### Svenska
- **Ny appikon överallt** — faktura med guldbock på marinblått, samma motiv i `.ico` (aktivitetsfältet), `.png` (fönster, flikrubriker, PDF-export, Linux `.desktop`) och handgjord `.svg`. - **Egen loggflik** (🪵 Logg, Ctrl+8) för felsökning: historik från `logs/app.log` även från föregående sessioner, felbanner med genväg till senaste felet, 🔖 markering + kopiera-efter-markering och ett **felsökningspaket** som kopieras med ett klick.

### English

The donate dialog and Log tab now also carry the icon, and view headers are unified (17 pt + 28 px icon) via the new `ui/design.py`.
